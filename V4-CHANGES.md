# Version 4 — что сделано по 17 комментариям

V4 — новая версия по умолчанию. V1–V3 остались доступны из экрана выбора (кнопка ✕ → выбор версии).

## Dashboard
1. **Иконки плашек** — убрал мелкий календарь, теперь крупная цифра периода (1 / 7 / 31) в контейнере; у сессии — иконка пауза.
2. **Уведомления** — верхний баннер убран, карточки подняты. Рядом с «Deposit limit» и «Session limit» — иконка «i»; по клику поповер с условиями: «New limits apply immediately» + «Edits and removals take effect after 24 hours» (для сессии добавлена строка про авто-логаут).
3. **Дата + обратный отсчёт** — статус показывает `11 Jun (23h 59m 05s)`, посекундно.
4. **Статус в карточке** — добавлен бейдж Updating/Removing с иконкой «i» под кнопками; верхняя строка Active on/Expires on убрана, инфо объединено в этот статус.
5. **Cancel removal** — на карточке в статусе removal кнопка «Remove» заменена на «Cancel removal» (отменяет удаление, лимит снова Active); «Edit» в этом состоянии скрыта.

## Редактор депозита
6. **Табы убраны** — Daily/Weekly/Monthly больше нет; период отражён в заголовке экрана («Daily limit» / «Weekly limit» / «Monthly limit»).
7. **Цвет ввода суммы** — placeholder теперь корректного цвета (как лейбл Amount), без затемнения.
8. **Хинт обычной суммы** — под пресетами компактный нейтральный блок: «Usually you deposit around X lei» + кнопка «Use X».
9. **Continue** — перекрашен в красный градиент (как Confirm). Кнопки выбора часов сессии и Edit на дашборде не трогал.
10. **Resulting changes** — копирайтинг переписан: существительное + тег действия (NEW / INCREASE / DECREASE / ADJUSTED / REMOVE) и подпись со временем («Applies immediately» / «Applies in 24h»). Отражает будущее действие, а не «updated».

## Review & Confirm
11. Нижний текст «Raising or removing a limit…» убран — кнопка опущена вниз.
12. Оба чекбокса убраны — на экране подтверждения только поле пароля.
13. **Иконка плюса** — сделана толще и контрастнее (фон бледно-зелёный не тронут).
14. Кнопка «Confirm new limit» → **«Activate protection»**.
15. Сообщение про усиление → **«This limit is stricter than your current one — it takes effect immediately.»**

## Логика подтверждения
16–17. Пароль теперь требуется на **любое** действие (изменение / повышение / понижение / удаление), **кроме самого первого создания** лимита (Daily/Weekly/Monthly/Session) — оно мгновенное и без пароля. Это работает и для удаления (на экране Remove добавлено поле пароля). Чекбоксы убраны везде.

## Открытые вопросы для тебя
- Тег DECREASE/Adjusted — цвета подобрал по смыслу (повышение — жёлтый, понижение — голубой). Скажи, если хочешь иначе.
- Поповер «i» открывается по клику (не по наведению) — так надёжнее на мобиле.
