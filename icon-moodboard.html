Иконки карточек — мудборд (100+ вариантов)

Библиотека Phosphor Icons (MIT, свободно). По категориям Daily / Weekly / Monthly / Session — десятки кандидатов в контексте иконки карточки. Переключай начертание сверху (Regular / Bold / Fill / Duotone). Кликай по иконкам, чтобы выбрать по одной на каждую категорию — внизу соберётся твой набор, который можно скопировать и прислать мне. Требуется интернет (иконки грузятся с CDN).

Начертание:
Твой набор (по клику на иконки): пока пусто
