Наборы иконок — 100 вариаций (акцент на время)

Каждая карточка — связное семейство из трёх иконок (день / неделя / месяц) в одном стиле; различается только таймфрейм (1 / 7 / 31 либо визуально). Только время: календари, часы, таймеры, цифры (в т.ч. в обёртке), кольца прогресса, полосы длительности. Без солнца/луны/монет/щитов. Кликни на понравившуюся — выбор внизу можно скопировать и прислать. Поле поиска фильтрует по названию.
